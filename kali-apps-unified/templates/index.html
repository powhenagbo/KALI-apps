How to interpret results
z > 4.0  Strong signal — high confidence HGT, likely prophage or pathogenicity island
z 2.5–4.0  Moderate signal — probable HGT, verify with gene content
GC deviation  Negative = insert from low-GC donor | Positive = insert from high-GC donor
Large islands  Single bins = recent/sharp insertion | Multi-bin = larger element or older/ameliorated

KALI vs Kraken2 — Publication Benchmark
Compares KALI classification against Kraken2 on the same stratified holdout set. Uses the same train/test split (random_state=42) as the Evaluate command for reproducibility. Produces the comparison table required by Oxford Bioinformatics reviewers.
Install Kraken2 (optional):
conda install -c bioconda kraken2
kraken2-build --download-taxonomy --db /path/to/db
kraken2-build --add-to-library train.fasta --db /path/to/db
kraken2-build --build --db /path/to/db
Robinson-Foulds Tree Distance
Compares your KALI-inferred tree against a reference tree (e.g. from FastTree or RAxML). Normalized RF distance close to 0 means high topological agreement. Required for Oxford reviewers.
Build a reference tree (run in terminal):
conda install -c bioconda muscle fasttree
muscle -in flaviviridae_370.fasta -out aligned.fasta
FastTree -nt -gtr aligned.fasta > reference.nwk
